# 📚 CampusHIVE – Library Management System

CampusHIVE is a beginner-friendly Library Management System frontend project developed using **HTML5 and Tailwind CSS**. It provides a simple and user-friendly interface for managing library books and student activities.

## 🚀 Features

- **Login Page** – User login interface.
- **Sign Up Page** – New user registration.
- **Student Dashboard** – Overview of  library activities.
- **Add Book** – Add new books with details and cover images.
- **View Books** – Browse available books and book information.
- **Issue Book** – Manage book issuing to students.
- **Return Book** – Manage returned books.
- **My Issued Books** – View student borrowing details.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Visual Studio Code
